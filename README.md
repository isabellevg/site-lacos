# 🐾 Laços — Adoção que transforma vidas

**Conectando pessoas e animais por meio da adoção responsável.**

O **Laços** é um site desenvolvido com o objetivo de aproximar pessoas que desejam adotar animais de estimação e pets que procuram um novo lar. A proposta é tornar o processo de adoção mais acessível, acolhedor e consciente, valorizando o amor, o cuidado e a responsabilidade.

## ✨ Sobre o projeto

O Laços nasceu da ideia de que todo animal merece uma oportunidade de encontrar uma família. Com um visual moderno, intuitivo e acolhedor, o site oferece uma experiência simples para quem deseja conhecer animais disponíveis para adoção.

## 🚀 Funcionalidades

- 🐶 **Galeria de animais:** apresentação dos pets disponíveis para adoção.
- 🔎 **Busca e filtros:** pesquisa por nome, espécie e porte.
- ❤️ **Favoritos:** possibilidade de favoritar os animais.
- 🐾 **Teste de afinidade:** questionário para sugerir um perfil de pet.
- 📋 **Detalhes dos animais:** informações sobre cada animal.
- 💌 **Manifestação de interesse:** formulário para demonstrar interesse em um pet.
- 🏡 **Cadastro de animais:** formulário para adicionar novos perfis.
- 📱 **Design responsivo:** adaptação para computadores e dispositivos móveis.

## 💻 Tecnologias utilizadas

- HTML5 — estrutura do site.
- CSS3 — estilização, cores, animações e responsividade.
- JavaScript — funcionalidades e interatividade.

## ▶️ Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Verifique se as imagens estão na mesma pasta do arquivo `index.html`.
4. Abra o arquivo `index.html` no navegador.
5. Pronto! O site estará disponível para visualização.

## 🎨 Identidade visual

O projeto utiliza uma identidade visual inspirada no acolhimento e na natureza, com tons de verde, cores suaves e elementos que transmitem carinho, confiança e cuidado.
